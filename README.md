## How I think about work

Good web products are not just polished screens.

They need clear product logic, usable flows, maintainable systems, good content structure, stable production behavior, sensible analytics, and enough care around edge cases so the thing does not break when real users or real data show up.

I care about building systems that are clean on the surface and sturdy underneath.

Tools matter, but only after the product logic is clear.
