# Audi Previo

Product designer and full-stack engineer in Bandung, Indonesia. I design and build web products end to end, from the flow and the interface to the code and the data behind it, and I stay until they hold up with real users.

Currently full-stack engineer and UX designer at [Bumiterra](https://bumi-terra.com), building forest-restoration maps and registry tools. On the side, [AudiWorks](https://audiworks.dev): a small practice for international clients.

### Selected work

- **[Firewatch](https://firewatch.bumi-terra.com)**: a public fire tracker, designed and shipped the same day a fire was reported near a restoration site. Admin and public maps run on one data source. Fires are marked inactive, never deleted.
- **Plastic Fischer**: Shopify checkout, subscriptions and automated certificates for a river-cleanup company. Caught a bug before launch that would have mailed one customer 250 certificates. 200+ certificates delivered, one defect in four months.
- **[Futures Imagined](https://futuresimagined.com)**: reworked a curator's site with Codex on a fork, read every line, and handed back a README her own coding agent could run.
- **[UnderChat](https://github.com/audiprevio/underchat-public-v02)**: a solo-built Undertale fan app with ten character personas on one chat engine. 10,244 messages and 5.6M tokens, Jan–Aug 2024.
